# DGE
Here I use R packages edgeR, limma and Glimma for pairwise differential gene expression analyses in three pairs of closely related Diospyros species growing in a common garden. Each pair consists of one species native to normal soil and one to ultramafic soil. Hence overlaps of differentially expressed genes in the three pairs are assessed.  
This code is adapted from https://bioconductor.org/packages/release/workflows/vignettes/RNAseq123/inst/doc/limmaWorkflow.html for my personal use.
